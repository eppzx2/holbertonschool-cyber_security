# Linux Security

## Overview

This module focuses on the essential practices and configurations required to secure Linux-based operating systems. It covers everything from user permission management to system hardening and auditing, providing the skills necessary to protect servers and workstations from unauthorized access and exploits.

## Learning Objectives

By completing this module, you will:

- Master **User & Privilege Management** through secure sudo configurations and ACLs
- Implement **System Hardening** techniques to minimize attack surfaces
- Secure remote access using **Advanced SSH Configuration** and key-based authentication
- Configure **Network Defenses** using host-based firewalls (UFW/IPTables) and Fail2Ban
- Utilize **Security Auditing** tools to identify vulnerabilities and rootkits
- Analyze system logs to detect and respond to suspicious activities

## Technical Stack

- **Hardening:** Lynis, SELinux
- **Access Control:** SSH, MAC, Sudoers
- **Networking:** UFW, IPTables 
- **Monitoring:** Journalctl
