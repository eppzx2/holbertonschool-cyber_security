# 0x0c. System Audit & Security Monitoring Scripts

## Description

This collection of Bash scripts is designed for security auditing and post-incident investigation. They automate the extraction of critical security events from system authentication logs (`auth.log`). These scripts are essential for SOC analysts and System Administrators to track firewall modifications and monitor user account management activities.

By filtering specific event signatures, these tools provide a clear view of how the system's security posture has changed over time.
